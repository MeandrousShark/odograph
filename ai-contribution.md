# AI and contributions

## How AI was used on this project

I used AI tools as development assistants on this project: implementation,
debugging, testing, review, and documentation. I directed the product and
design decisions, and I reviewed and tested the resulting work before release.

Every release is signed and traceable to the exact source commit and CI run
that built it. The verification commands are in
[docs/releasing.md](docs/releasing.md).

## AI-assisted contributions

AI-assisted contributions are welcome under the same standard as any other. You
must understand every change you submit, have tested it, be able to explain it
in review, and take responsibility for it.

Pull requests that look like unreviewed bulk generated output are closed.
